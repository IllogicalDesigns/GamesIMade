Description

Left mouse to move objects and scale them based on perspective. Right mouse can rotate the held object. C to crouch, space to jump, Q or E to lean. Tab can be used to pause. There was a bug that only occured at certain frame rates causing an infinate loop. This is fixed in this version https://illogicaldesigns.itch.io/scaled-to-fit-physics-fixed Submission for GMTK jam. So much was left on the game jam floor. So its a very short game about escaping through scaling.
